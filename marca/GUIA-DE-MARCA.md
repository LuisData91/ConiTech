# ConiTech | Software & Automation — Guía de marca

## Concepto del logo
Una **C formada por bloques** (módulos de software). El bloque naranja que falta **llega solo a su lugar**: representa la automatización, sistemas que se arman y funcionan por sí mismos.

## Colores
| Uso | Nombre | HEX |
|---|---|---|
| Principal (bloques, inicio del degradado) | Azul marino | `#0B2A5B` |
| Principal (bloques, fin del degradado) | Azul intenso | `#1E40AF` |
| Acento (bloque que llega, separador, botones) | Naranja ConiTech | `#F97316` |
| Texto "Coni" / títulos | Marino tinta | `#0B1E3F` |
| Texto "Tech" / enlaces | Azul Tech | `#1D4ED8` |
| Texto secundario | Gris pizarra | `#475569` |
| Fondo oscuro | Noche | `#0B1220` |
| Bloques sobre fondo oscuro | Azul claro → intenso | `#3B82F6` → `#1D4ED8` |
| "Tech" sobre fondo oscuro | Azul cielo | `#60A5FA` |

Regla: el naranja es el **acento**; úsalo poco (botones de acción, detalles), nunca como fondo principal.

## Tipografías (gratuitas, Google Fonts)
- **Space Grotesk Bold**: nombre de marca y títulos.
- **Inter SemiBold / Regular**: subtítulos y textos.

## Buen uso
- Deja aire alrededor del logo, al menos el ancho de un bloque.
- No cambies los colores, no estires el logo y no le pongas sombras.
- En tamaños pequeños (menos de 120 px de ancho), usa solo el icono.
